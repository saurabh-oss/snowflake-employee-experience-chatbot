## 🎯 Key Features

✅ **No data egress** - All computation stays inside Snowflake  
✅ **Zero setup time** - 30 minutes from clone to running  
✅ **Built-in governance** - Automatic masking, RBAC, audit logs  
✅ **Production-ready** - Security, compliance, and scalability

## 💡 What You'll Learn

- How to build AI chatbots securely on Snowflake Cortex
- Design patterns for NL-to-SQL with Cortex Analyst
- Implementing row and column-level security (masking, RBAC)
- Hybrid search (semantic + keyword) with Cortex Search
- WebSocket-based streaming for better UX
